# AutoLarp
Please read original Github repo at: https://github.com/zainaleem906/AutoLarp

This Github repo aims to recreate the original AutoLarp application without the online database requirement, can be run locally. There is no MongoDB and no login: the app stores everything in `data/autolarp.json` and you are signed in automatically as a single local user. Just run `npm start` (Node >= 22) and open http://localhost:8080.
